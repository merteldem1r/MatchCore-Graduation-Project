# Submissions

Our filled-in versions of the official templates, kept here once they are written.

Each document has a Markdown source (`.md`, committed, no personal data) and the filled template (`.docx`) plus its `.pdf` export, which is the file that gets sent. Both are ignored by git because they hold the student number and the advisor's details. The text uses Turkish sentences with English technical terms; the title is in both Turkish and English (D15).
